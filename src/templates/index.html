How it works

  1. Paste a public link. Long articles with tables, like Wikipedia pages, work best. Private and local addresses are blocked.
  2. WebScrapeAI reads the page. The server fetches the page text and counts its headings, paragraphs, links, images and tables.
  3. Question it. You get an overview, key findings backed by quotes from the page, and follow-up questions you can click.
